# TravelBus - Simple Bus Company Website

A simple, responsive HTML/CSS/JavaScript website for a bus company.

## 📁 Files Included

- **index.html** - Home page with booking search form
- **routes.html** - Available routes and schedules
- **about.html** - Company information and mission
- **contact.html** - Contact information and contact form
- **styles.css** - All styling for the website
- **script.js** - JavaScript for interactivity (search, booking)

## 🚀 How to Use

1. **Open the website:**
   - Simply open `index.html` in your web browser
   - All pages are linked in the navigation menu

2. **Book a Ticket:**
   - Fill in "From", "To", "Date", and number of "Passengers"
   - Click "Search Buses"
   - View available buses and click "Book Now"

3. **Explore:**
   - Click "Routes" to see all available routes
   - Click "About" to learn about the company
   - Click "Contact" to reach out or see contact information

## 🎨 Customization

To customize the website:

1. **Change Company Name:**
   - Replace "TravelBus" with your company name in all HTML files
   - Change the emoji (🚌) if desired

2. **Add Your Routes:**
   - Edit `routes.html` and modify route information
   - Update `busData` in `script.js` with real bus data

3. **Update Contact Info:**
   - Edit email addresses in `contact.html`
   - Add your actual phone number and address

4. **Change Colors:**
   - Edit the color codes in `styles.css`
   - Main colors: #667eea (purple), #764ba2 (dark purple), #2c3e50 (dark)

5. **Add Your Logo:**
   - Replace the emoji with an actual logo image

## 📱 Responsive Breakpoints

- **Desktop:** Full layout with multiple columns
- **Tablet:** 2-3 column grids
- **Mobile:** Single column layout
